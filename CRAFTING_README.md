# Калькулятор v2.3.3

Калькулятор открывается отдельной полноценной страницей `crafting/index.html`, без iframe. На основной странице в разделе «Ремёсла» есть кнопка перехода. Ссылка «К братству» возвращает обратно.

Во вкладке «Расчёт заказа» появилась кнопка копирования сводного списка исходных ресурсов и количества к покупке. Источник — уже рассчитанная таблица `rawsum`; формулы не изменены.

Цены остаются индивидуальными и сохраняются локально. Supabase и SQL не нужны. Старые данные калькулятора сохраняются в localStorage того же домена.

Проверьте опубликованную версию на мобильном устройстве, в особенности таблицы и возврат на сайт.
