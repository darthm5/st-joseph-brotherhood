# v2.3 — самостоятельный калькулятор ремёсел (первая итерация)

В разделе «Ремёсла» добавлена вкладка «Калькулятор ремёсел» с девятью ремёслами, редактором рецептов, ценами материалов, корзиной, расчётом потребности и журналом продаж.

Это собственная реализация, а не копия DanekKuznec/kcd2-rp-crafting. У исходного репозитория отсутствует явная лицензия; для копирования кода/данных нужно разрешение правообладателя. База рецептов не скопирована: пользователь добавляет рецепты вручную. Никаких демонстрационных рецептов с выдуманными числами нет.

Все данные калькулятора хранятся в localStorage текущего браузера. Это не Supabase: пока нет синхронизации между устройствами и пользователями. Разделы «Склад фракции» и «Данные» из оригинального калькулятора не добавлялись. Существующая «Кладовая» сайта не затронута.

Важно: себестоимость изделий считается по количеству ресурсов и плате за верстак; округление крафтов используется при подсчёте общего сырья. Вложенные заготовки, наценки, аукционные цены и интеграция с Supabase пока не реализованы.

SQL не требуется. Для установки замените файлы сайта в GitHub Pages. Не удаляйте craft-calc.js.
