# v2.3.1 — Счётная книга братства

Оригинальный расчётный движок и база рецептов DanekKuznec перенесены в локальный модуль `crafting/`, встроенный в страницу «Ремёсла» через iframe для изоляции стилей и скриптов. Склад фракции, заказы фракции и вкладка «Данные» скрыты/отключены; личный склад калькулятора сохранён. Модуль не использует Supabase склада оригинального автора. Авторизация братства остаётся на основном сайте. Локальные заказы и цены калькулятора сохраняются в localStorage браузера. Для GitHub Pages загрузите всю папку `crafting/` без изменений. SQL не требуется.

Старый упрощённый craft-calc.js остаётся в архиве для резервной копии, но не подключается.
