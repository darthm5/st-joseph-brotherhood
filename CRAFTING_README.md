## v2.4.5 — склад братства
База v2.4.3, без переключателя «Изготовить/Купить». Добавлены выбор источника ресурсов, просмотр кладовой и соответствие названий. Для выдачи используется существующий storage_submit_request, подтверждение в штатной Кладовой через storage_review_request. Каждая позиция — отдельная заявка, НЕ атомарный пакет. Частично одобренные заявки уже списывают остатки. Кнопка «Проверить одобрение и завершить» фиксирует выполнение после одобрения всех заявок, не списывая повторно. Отмена списания братства из калькулятора недоступна. Для личного склада поведение прежнее. SQL не нужен при наличии действующих RPC кладовой.
